# UX & Screen Specification: InvoiceCreate (Lập Hóa Đơn Mới)

> **Graph Node ID:** `InvoiceCreate`  
> **Route:** `/invoices/new`  
> **Title:** `Create Draft Invoice - Lập Hóa Đơn Mới`  
> **Authentication & Role:** `AUTHENTICATED`  
> **Parent / Layout Context:** Root Main Application Layout  
> **Mounted Islands:** `GlobalHeaderIsland`, `InvoiceFormIsland`

---

## 1. Executive Summary & Screen Purpose

The **InvoiceCreate** screen provides an intuitive, high-efficiency data entry interface for creating new commercial draft invoices. It features real-time calculation engines (`calculateInvoiceTotals`), live Vietnamese currency-to-words translation (`convertVndToWords`), dynamic multi-row item management (supporting up to 100 line items), and proactive client-side Zod validation with smooth feedback animations.

Upon successful submission, the system creates the invoice in `DRAFT` status with a guaranteed sequential number (`HD-YYYY-XXXXX`) generated by PostgreSQL sequence, then seamlessly routes the user to the newly generated `InvoiceDetail` page.

```mermaid
graph TD
    InvoiceCreate["UINode: InvoiceCreate (/invoices/new)"]
    InvoiceCreate --> GlobalHeaderIsland["SharedIsland: GlobalHeaderIsland"]
    InvoiceCreate --> InvoiceFormIsland["SharedIsland: InvoiceFormIsland"]

    InvoiceFormIsland -->|cancelFormAndReturnToList| InvoiceList["/invoices"]
    InvoiceFormIsland -->|recalculateTotals| InvoiceFormIsland
    InvoiceFormIsland -->|liveConvertVndToWords| InvoiceFormIsland
    InvoiceFormIsland -->|submitDraftInvoice (POST /api/v1/invoices)| InvoiceDetail["/invoices/:id"]
```

## 2. Visual Hierarchy & Action Architecture

### 2.1 Primary Action (Single CTA Priority)
* **Action:** `💾 Lưu Bản Nháp Hóa Đơn` (`submitDraftInvoice` -> `POST /api/v1/invoices`)
* **Placement:** Bottom-right sticky action footer bar & Top-right form header.
* **Visual Style:** Solid High-Contrast Primary Button (`bg-primary-600 hover:bg-primary-700 text-white font-semibold px-6 py-2.5 rounded-lg shadow-sm hover:shadow transition-all duration-200`).
* **Keyboard Shortcut:** `Ctrl + S` / `Cmd + S`.

### 2.2 Secondary Actions (Downgraded Controls)
* **`+ Thêm Dòng Hàng Hóa / Dịch Vụ`:** Outline dashed button placed directly beneath the line items table (`border-dashed border-2 border-primary-300 text-primary-700 hover:bg-primary-50 w-full py-2.5 font-medium rounded-lg`). Keyboard shortcut: `Alt + A`.
* **Quick VAT Selectors:** Segmented pill selector buttons for standard VAT rates (`0%`, `5%`, `8%`, `10%`, `Không chịu thuế`).
* **Autofill Recent Customer:** Typeahead dropdown in Buyer Tax Code / Name fields to rapidly load saved enterprise profiles.

### 2.3 Cancel / Escape Action
* **Action:** `✕ Hủy Bỏ` (`cancelFormAndReturnToList` -> `/invoices`).
* **Visual:** Ghost button (`text-slate-600 hover:text-slate-900 hover:bg-slate-100 font-medium px-4 py-2.5 rounded-lg`).
* **Guard:** If the form is "dirty" (user has entered data), triggers an in-app confirmation modal: *"Bạn có những thay đổi chưa được lưu. Bạn có chắc chắn muốn rời khỏi trang này không?"*.

## 4. Mounted Island Detailed Specifications: `InvoiceFormIsland`

### 4.1 Form Section 1: Parties Profile (Thông Tin Bên Bán & Bên Mua)
* **Seller Details (Read-only / Pre-configured):**
  - Company Legal Name (`sellerName`).
  - Tax Code (`sellerTaxCode`).
  - Address (`sellerAddress`), Email (`sellerEmail`), Bank Account Info (`sellerBankAccount`, `sellerBankName`).
* **Buyer Details (Editable Form Inputs):**
  - **Tên người mua / Đơn vị mua hàng (`buyerName`):** `Input[type="text"]` (Required, min 2 chars, max 255 chars).
  - **Mã số thuế bên mua (`buyerTaxCode`):** `Input[type="text"]` (Optional / Vietnamese Tax Code regex format `^[0-9]{10}(-[0-9]{3})?$`).
  - **Địa chỉ bên mua (`buyerAddress`):** `Input[type="text"]` (Optional, max 500 chars).
  - **Email nhận hóa đơn (`buyerEmail`):** `Input[type="email"]` (Optional, standard email validation).
  - **Số điện thoại (`buyerPhone`):** `Input[type="tel"]` (Optional).
  - **Hình thức thanh toán (`paymentMethod`):** `Select` dropdown (`Chuyển khoản`, `Tiền mặt`, `Chuyển khoản / Tiền mặt`, `Đối trừ công nợ`). Default: `Chuyển khoản`.

### 4.2 Form Section 2: Interactive Line Items Matrix (Danh Mục Hàng Hóa)
* **Dynamic Table Grid:**
  - **STT (Index):** Auto-incremented sequence number (1, 2, 3...).
  - **Tên Hàng Hóa / Dịch Vụ (`itemName`):** `Textarea[rows=1]` with auto-resize for multi-line service descriptions. Required.
  - **Đơn Vị Tính (`unit`):** `Input[type="text"]` or quick autocomplete (Cái, Chiếc, Bộ, Gói, Giờ, Tháng, Lô, Kg, Mét). Required.
  - **Số Lượng (`quantity`):** `Input[type="number"]` (Min: 0.0001, Step: any, Default: 1). Triggers `recalculateTotals` on change.
  - **Đơn Giá (`unitPrice`):** `Input[type="text"]` with currency mask formatting (e.g. typing `15000000` formats live as `15,000,000`). Triggers `recalculateTotals` on change.
  - **Thành Tiền (`lineTotal`):** Read-only calculated field (`quantity * unitPrice`) formatted with thousand separators.
  - **Xóa Dòng (Delete Item):** Destructive trash icon button. Disabled if only 1 row remains (minimum 1 item required).
* **Keyboard Navigation in Table:**
  - Pressing `Tab` at the end of the last row's unit price automatically creates a new row and focuses its item name input.

### 4.3 Form Section 3: Summary & Real-Time Financial Calculations
* **State Mutation:** `recalculateTotals` & `liveConvertVndToWords`.
* **Form Controls & Outputs:**
  - **Ghi chú (`note`):** `Textarea` for invoice memos or contract references.
  - **Cộng Tiền Hàng (Subtotal):** Live sum of all item line totals.
  - **Thuế Suất GTGT (`vatRate`):** Interactive segmented toggle (`0%`, `5%`, `8%`, `10%`). Defaults to `10%`. Custom rate input available if needed.
  - **Tiền Thuế GTGT (`vatAmount`):** Calculated as `Math.round(Subtotal * vatRate / 100)`.
  - **Tổng Tiền Thanh Toán (`totalAmount`):** Large display badge `Subtotal + vatAmount`.
  - **Số Tiền Bằng Chữ (`amountInWords`):** Live synchronization from Vietnamese number-to-words converter (e.g., *"Ba mươi tám triệu năm trăm nghìn đồng chẵn."*). Rendered in distinct italic badge to prevent discrepancy errors.

## 5. Micro-Interactions, Feedback & State Transitions

| Trigger / Event | UI Transition / Animation | Visual Feedback |
|---|---|---|
| Form Submit (`submitDraftInvoice`) | `isSubmitting == true` -> `pulse` animation | Save button shows spinner and disables all inputs to prevent double-submit. |
| Validation Error | `validationError != null` -> `shake` animation | Errored input borders turn red (`border-rose-500`) with shake micro-animation and scroll to first error. |
| Add Line Item | Slide-down fade-in (150ms ease-out) | New row smoothly slides in with focus automatically placed on Item Name. |
| Delete Line Item | Slide-up fade-out (150ms ease-in) | Row collapses cleanly and totals recalculate immediately. |
| Currency Mask Input | Real-time mask | Formats numbers with Vietnamese comma thousand separators as user types. |

## 6. Edge Cases & Error States

### 6.1 Validation Rules & Error Messages
* **Empty Line Items:** Form blocks submission if 0 items are present.
* **Negative or Zero Quantity/Price:** Displays inline error *"Số lượng và đơn giá phải lớn hơn 0"*.
* **Invalid Tax Code:** If entered, checks length (10 or 14 digits) and warns if format does not match standard Vietnamese tax codes.
* **Invalid Email:** Displays inline badge *"Email không đúng định dạng"*.

### 6.2 Network Error / Submission Failure
* **Toast Notification:** Danger banner with specific backend message (`AppError.message`).
* **Data Retention:** Form data is preserved in state so the user never loses entered information on submission error.

### 6.3 Large Item Volumes (50 - 100 items)
* Table body uses virtualized rendering or optimized DOM nodes to ensure zero keystroke latency even with 100 items.

## 7. Responsive Specifications

* **Desktop (>= 1280px):** Two-column split for Party Info, full-width data matrix for Line Items, split bottom row for Notes and Totals Summary.
* **Tablet (768px - 1279px):** Single-column stacked layout with horizontal scroll on Line Items table.
* **Mobile (< 768px):** Line items switch from table to expandable card list format (each item displayed as a stacked card with compact quantity & price fields). Sticky bottom CTA bar with single tap `[💾 Lưu Hóa Đơn]`.
